# KES Energy — Multilingual Landing Page (WordPress)

Live: https://kesenergy.es/

---

## Project Type

The website presents Battery Energy Storage Systems (BESS) solutions, company expertise, services and lead generation for commercial clients.

---

## Project Goals

- Present company expertise in energy storage solutions
- Generate business leads
- Provide clear service overview
- Support multiple languages
- Ensure fast loading and clean structure

---

## Multilingual Implementation

The landing page supports multiple languages.

Implemented using:

- WordPress
- Multilingual plugin Polylang
- Language switcher in header
- Separate translated content managed via ACF

Structure ensures:

- SEO-friendly language URLs
- Independent content editing per language
- Clean separation of translated fields

---

## Architecture & Development Approach

### KSENERGY Theme

Fully custom WordPress theme.
No page builders (no Elementor, no WPBakery).
Modular structure with reusable components.

---

### Flexible Content Structure

Landing sections are built using:
- ACF Flexible Content
- Reusable section templates
- Clean separation between logic and markup

This allows:
- Easy content management
- Quick addition of new sections
- Structured layout without page builders

---

### ACF JSON Integration

All field groups are stored in: /wp-content/themes/your-theme/acf-json/

Benefits:
- Version control compatibility
- Easy migration between environments
- No manual recreation of fields

---

## Responsive & Performance

- Fully responsive layout
- Optimized CSS structure (SCSS)
- Lightweight JS
- Semantic HTML
- Optimized for fast loading

---

## Technical Decisions

- Custom theme instead of builder → better performance and maintainability
- ACF Flexible Content → scalable section management
- Multilingual architecture → structured translation system
- Modular SCSS → maintainable styling system
